# Дополнительные замеры для статьи computers-4623431 (второй раунд)

Рецензент попросил повторить замеры на том же ноутбуке, что и в первый раз (ASUS ROG Strix SCAR 18), с тремя
независимыми процессами на каждый замер, одной схемой питания для всех прогонов и журналом частот видеокарты, а также
измерить оптимизированные варианты CPU и GPU и снять счётчики ядер в Nsight Compute. Набор делает всё это сам; прогон
идёт без участия человека и занимает около 2,5–3 ч, счётчики — ещё 5–10 мин.

## Что нужно

- Тот же ноутбук и та же Windows, что в первый раз.
- [.NET 8 SDK](https://dotnet.microsoft.com/download/dotnet/8.0) (уже установлен с первого раза; проверка:
  `dotnet --list-sdks` выводит строку, начинающуюся с `8.0`).
- Драйвер NVIDIA (CUDA Toolkit не нужен). Интернет на время первой сборки: пакеты ILGPU и BenchmarkDotNet
  скачиваются из NuGet.
- Не меньше 5 ГБ свободного места на диске C: (временные файлы до 3 ГБ).
- Для счётчиков (последний шаг): NVIDIA Nsight Compute — бесплатно, https://developer.nvidia.com/nsight-compute
  (нужна учётная запись NVIDIA Developer; входит также в CUDA Toolkit).

## Подготовка

1. Распаковать архив в папку с коротким путём без пробелов и русских букв, например `C:\assoc2`.
   Можно вместо архива обновить репозиторий с первого раза (`git pull`); тогда ниже вместо `C:\assoc2` —
   папка репозитория.
2. Ноутбук подключить к сети. Закрыть остальные программы: браузер, среду разработки, игры, облачные клиенты.
3. В Armoury Crate выбрать режим **Turbo** (если его нет — Performance) и не менять до конца замеров.
   Режим работы видеокарт (GPU Mode) оставить тем же, что в первый раз: должны работать и встроенная графика,
   и NVIDIA (режим Standard/Optimus, не Ultimate).
4. Схему питания Windows скрипт переключает сам и потом возвращает прежнюю.
5. Во время прогона компьютером не пользоваться. Запускать из обычной консоли (cmd), не из Visual Studio.

## Запуск

Открыть консоль в папке набора:

```
cd /d C:\assoc2\measurement\laptop
```

**1. Проба** (1–3 мин; при первом запуске дольше из-за скачивания пакетов):

```
run_revision2.cmd ..\..\data\ru_10MB.bin ..\..\data probe
```

Скрипт спросит режим Armoury Crate — ввести его (например, `Turbo`) и нажать Enter. Проба прошла, если в конце
выведено `probe passed`. Если нет — прислать папку `results_revision2` (см. ниже) и дальше не продолжать.

**2. Полный прогон** (около 2,5–3 ч):

```
run_revision2.cmd ..\..\data\ru_10MB.bin ..\..\data
```

| Группа | Что измеряется | Время |
|---|---|---|
| env | сведения о системе | < 1 мин |
| breakeven | полный цикл 1 KB – 1 MB: эталонный CPU, оптимизированный CPU, оба GPU в исходном и оптимизированном вариантах | 50–70 мин |
| formation | формирование 10 MB | около 15 мин |
| recovery | восстановление 10 MB | около 20 мин |
| fullcycle | полный цикл 100 MB | около 40 мин |
| fullcycleseq | полный цикл 100 MB на эталонном CPU | около 8 мин |
| kernels | время ядер при разных размерах группы потоков | 10–15 мин |

Если прогон прервался, можно запустить одну группу: её имя — третий аргумент, например
`run_revision2.cmd ..\..\data\ru_10MB.bin ..\..\data fullcycle`.

**3. Счётчики Nsight Compute** (5–10 мин). Сначала открыть доступ к счётчикам видеокарты: NVIDIA Control Panel →
меню Desktop → Enable Developer Settings, затем Developer → Manage GPU Performance Counters → «Allow access to the GPU
performance counters to all users» (или запустить консоль от имени администратора). Затем:

```
run_revision2.cmd ..\..\data\ru_10MB.bin ..\..\data ncu
```

Если Nsight Compute не установлен, этот шаг можно пропустить — остальные результаты от него не зависят.

## Что прислать

Папку `results_revision2` (она рядом со скриптом) целиком, архивом zip.

Результаты будут опубликованы в открытом репозитории статьи. В них есть модель компьютера, процессор, видеокарты, объём
памяти, версии Windows, .NET и драйверов, схема питания и режим Armoury Crate; серийных номеров и имени пользователя нет,
если набор лежит в папке вроде `C:\assoc2`.

## Если что-то пошло не так

- **Сборка не прошла** — прислать `results_revision2\build.log`.
- **Группа завершилась с ошибкой** — прислать `results_revision2\<Класс>.console.log` (например,
  `Rev2Recovery.console.log`) или `kernels2.err`.
- **Счётчики: в `ncu_dGPU_*.log` есть ERR_NVGPUCTRPERM** — нет доступа к счётчикам; см. шаг 3.
