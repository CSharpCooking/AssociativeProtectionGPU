# Запуск замеров для статьи computers-4623431

Набор измеряет время ассоциативного преобразования данных на CPU, на встроенной графике (через OpenCL) и на
видеокарте NVIDIA (через CUDA). Результаты его прогона на конфигурации D вошли в исправленную версию статьи. Полный
прогон идёт без участия человека; на конфигурации D (Core i9-14900HX) он занял около 45 мин, на более медленном
компьютере займёт в несколько раз больше.

## Что нужно

- Windows 10 или 11, 64-разрядная.
- [.NET 8 SDK](https://dotnet.microsoft.com/download/dotnet/8.0). Проверка: команда `dotnet --list-sdks` выводит
  строку, начинающуюся с `8.0`.
- Свежий драйвер NVIDIA. CUDA Toolkit не нужен.
- Интернет на время первой сборки: пакеты ILGPU и BenchmarkDotNet скачиваются из NuGet.
- Не меньше 5 ГБ свободного места на диске C: во время замеров создаются временные файлы до 3 ГБ.

## Подготовка

1. Скопировать репозиторий (на GitHub: Code → Download ZIP, или `git clone`) в папку с коротким путём без пробелов
   и русских букв, например `C:\assoc`.
2. Закрыть остальные программы: браузер, среду разработки, игры, клиенты облачных хранилищ.
3. Выбрать в Windows схему питания «Высокая производительность»; ноутбук подключить к сети. Если у ноутбука есть
   фирменная утилита управления питанием (например, Armoury Crate), выбрать в ней режим «Производительность» или
   «Турбо».
4. Во время прогона компьютером не пользоваться. Запускать из обычной консоли (cmd или PowerShell), а не из
   Visual Studio, чтобы к процессу не был подключён отладчик.

## Запуск

Открыть консоль в папке набора `measurement\laptop`:

```
cd /d C:\assoc\AssociativeProtectionGPU\measurement\laptop
```

**Проба** (несколько минут, при первом запуске дольше из-за скачивания пакетов):

```
run_revision.cmd ..\..\data\ru_10MB.bin ..\..\data formation
```

Проба прошла, если в конце выведено `done`, а в папке `results_revision\RevFormation\results` появились отчёты
`RevFormation-report-github.md`, `.csv` и `.html`.

**Полный прогон:**

```
run_revision.cmd ..\..\data\ru_10MB.bin ..\..\data
```

Группы идут по очереди; время — на конфигурации D (Core i9-14900HX), на более медленном компьютере оно в несколько
раз больше (оценки, которые печатает скрипт, сделаны до прогона):

| Группа | Время |
|---|---|
| env — сведения о системе | < 1 мин |
| breakeven | 2 мин |
| fullcycle | 6 мин |
| formation | 1 мин |
| chunksize | 17 мин |
| recovery | 4 мин |
| recognition | 9 мин |
| kernels | несколько минут |

Если прогон прервался, можно запустить одну группу: имя группы — третий аргумент, например
`run_revision.cmd ..\..\data\ru_10MB.bin ..\..\data chunksize`.

## Что прислать

Папку `results_revision` (она рядом со скриптом) целиком, архивом zip.

Результаты будут опубликованы в открытом репозитории статьи. Файл `env.txt` содержит модель компьютера, процессор,
видеокарту, объём памяти, версии Windows, .NET и драйверов, схему питания. Серийных номеров и имени пользователя в
нём нет; в пути к папке набора имени пользователя тоже не будет, если скопировать репозиторий в `C:\assoc`.

## Если что-то пошло не так

- **Сборка не прошла.** Прислать `results_revision\build.log`. На конфигурации D набор собрался с настоящими пакетами
  без правок.
- **Группа завершилась с ошибкой.** Прислать `results_revision\<Класс>.console.log` (например, `RevRecovery.console.log`).
- **Сообщения `iGPU is not available on this machine`** — это нормально, если у компьютера нет встроенной графики
  или она отключена: эти варианты пропускаются, замеры на видеокарте NVIDIA идут.
- **Видеокарт NVIDIA несколько.** Берётся та, у которой больше памяти.
- **Не хватает места на диске C.** Освободить около 5 ГБ и запустить прервавшуюся группу ещё раз.

## По желанию: профиль ядер

Если установлен Nsight Compute (входит в CUDA Toolkit) и разрешён доступ к счётчикам производительности GPU (панель
управления NVIDIA → режим разработчика → доступ к счётчикам для всех пользователей, либо консоль от имени
администратора), в папке `standalone` выполнить:

```
cd /d C:\assoc\AssociativeProtectionGPU\measurement\laptop\standalone
ncu --target-processes all --set full --export rev_kernels_dgpu dotnet run -c Release --no-build -- rev-kernels ..\..\..\data 1 dGPU
ncu --import rev_kernels_dgpu.ncu-rep --page details --csv > rev_kernels_dgpu.csv
```

Прислать оба файла: `rev_kernels_dgpu.ncu-rep` и `rev_kernels_dgpu.csv`.
